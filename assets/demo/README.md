# Bundled demo assets

Everything here ships **inside the repo** so a fresh clone can run real
detection and real mAP evaluation in under 30 seconds — no downloads,
no network, no weights hunting.

| File | Size | What it is |
|---|---|---|
| `synthetic-shapes-yolov8n.onnx` | 12 MB | YOLOv8n fine-tuned on the synthetic dataset below, exported to ONNX. Runs on CPU via ONNX Runtime — no PyTorch required. |
| `synthetic-shapes-dataset.zip` | 0.4 MB | 144-image (120 train / 24 val) copyright-free synthetic dataset: colored rectangles with noise, 3 classes (`0 obito`, `1 naruto`, `2 gaara`), YOLO format with a portable `dataset.yaml`. |

## Try it

```bash
# Unzip the bundled dataset anywhere, then run real inference on a val image:
python -c "
import zipfile
from pathlib import Path
tmp = Path('runs/bundled-demo'); tmp.mkdir(parents=True, exist_ok=True)
zipfile.ZipFile('assets/demo/synthetic-shapes-dataset.zip').extractall(tmp)
print(tmp / 'dataset' / 'images' / 'val' / 'naruto_000.jpg')
"
hokage-vision detect image runs/bundled-demo/dataset/images/val/naruto_000.jpg \
  --backend ultralytics --model-path assets/demo/synthetic-shapes-yolov8n.onnx \
  --conf 0.5 --imgsz 320
```

Expected metrics: `mAP50 0.995`, `precision 0.994`, `recall 1.0`.
